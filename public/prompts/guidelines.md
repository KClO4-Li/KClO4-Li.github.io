# 实验报告生成 — 注意事项与检查清单

本文档是 prompt.md 的补充检查清单, 用于生成完成后的逐项核对. 详细规范见 prompt.md, 本文不再重复.

---

## 一、流程清单

1. **分析**: 解析讲义 (目的/原理/仪器/步骤/思考题), 读取原始数据, 用 `node D:\A\pdf-reader.mjs` 提取 PDF 文本
2. **展示思路**: 在客户端窗口输出数据处理思路和报告生成计划
3. **检查数据口径**: 数据包已有最终分析图和拟合参数? → 直接引用, 不复算不重复拟合
4. **生成文件**: 主报告 .typ + Python 脚本 + r.yaml; **预习报告仅在用户明确要求时生成**
5. **编译验证**: `typst compile` 零报错, 逐页检查 PDF (见第三节)
6. **清理**: 删除中间脚本和临时文件, 只保留最终版本
7. **列出待补充信息**: 指导老师、未确定的拟合方法等, 等用户回复后完善

**默认值**: 日期用当日 `YYYY年M月D日`; 指导老师未提供时 `guide: [指导老师: ]`; `part` 推荐 `(50%, 20%, 20%)`, 标题长时调整.

## 二、源码格式检查点

### 标点 (最易出错)
- [ ] 正文逗号为半角 `, `, 句号为半角 `. `
- [ ] 全文搜索 `，` 和 `。`, 数量极少或为零

### Typst 语法
- [ ] `#import` 在文件最开头, `#show: project.with(...)` 紧随其后
- [ ] `#qty()` 数值和单位都有引号: `#qty("5.486", "MeV")`
- [ ] `#qty()` 不出现在 `$...$` 数学模式内
- [ ] 显示公式前后各有空行
- [ ] 图片路径正确: 原理图 `assets/`, 数据图根目录 `Figure_*.png`
- [ ] 表格和图片都有 `#figure(..., caption: [...])`
- [ ] 核素写法 `$""^241"Am"$` (质量数前有空字符串)
- [ ] 无 LaTeX 残留: `\_` `\[` `\]` `left(` `right)` (完整错误表见 prompt.md 第七节)

### 物理规范
- [ ] 所有数值结果带单位, 公式内单位正体
- [ ] 近似估计明确标注假设条件, 不把近似写成严格结论
- [ ] 区分本征性能与系统等效结果

---

## 三、编译后 PDF 检查清单 (不可省略)

- [ ] `typst compile` 零报错
- [ ] 逐页检查公式渲染: 上下标、核素质量数、分数分组、希腊字母、单位正体
- [ ] 无异常空白页或强制换页留下的大片空白
- [ ] 图片表格未溢出页宽, 图注表注完整
- [ ] 页眉三栏 (标题/姓名/日期) 不挤压, 标题过长时已调整 `part`
- [ ] 每张 Figure: 曲线未超出边框, 虚线分区 (非色块), 黑白打印可区分
- [ ] 排版异常时先查 Typst 官方文档定位原因, 不盲目调整图片尺寸

---

## 四、内容检查清单

### 摘要
- [ ] 概括目的、方法、主要结果和结论, 含 1-2 个关键数值, 150-250 字

### 引言
- [ ] 编号列表形式的目的已合并为连贯段落, 以"本实验旨在..."收束, 无照抄讲义

### 实验原理
- [ ] 关键公式齐全, 按 subsection 分主题, 有原理示意图, 引用 `@manual`

### 实验方法
- [ ] 先总览再分步, 每步有目的说明, 无"打开开关"式操作细节

### 结果与讨论
- [ ] 每个测量量: 数据表 → 拟合图 → 代入数值的计算过程 → 结果分析
- [ ] 讨论物理意义、理论比较、误差来源、拟合优度

### 结论
- [ ] 含关键数值结果 (`#qty` 格式), 呼应引言的实验目的

### 通用
- [ ] 无连续照抄讲义超过 2 句的段落
- [ ] 参考文献除讲义外适当添加教科书引用

## 五、experiment 包使用要点

- 入口 `l.typ` 导出 `project`; 依赖 `@preview/chic-hdr:0.5.0`, `@preview/cuti:0.2.1`
- 字体: 黑体 SimHei, 宋体 SimSun, 楷体 KaiTi, 英文 Times New Roman
- `abstract: none` 和 `keywords: none` 时对应区域完全不渲染 (预习报告用此特性)
- 标题含数学符号时拼接: `"半导体 " + $alpha$ + " 谱仪"`
- `part` 库内默认 `(34%, 40%, 20%)`, 控制页眉三栏宽度
